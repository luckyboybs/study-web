# ANTI-SLOP-CHECK · 学迹登录页

> 账本与 `login/` 同为交付的一部分。只记录路由到的、实际可能命中的组。
> 本页是功能性认证页，主要风险组：G（灰色小字）、N（数字卡）、P（配色模板）、
> B（表达块）、H（待补占位）、T（胶囊堆）、O（双语眉题）、W（模板文案）、D（插画画风）。
> 低风险组（S 编号字诀、C 假数据等）本页不涉及，不写空章节。

## 1. 风险路由与预案（方向阶段）

| 组 | 风险 | 本页的预案 |
| --- | --- | --- |
| G | 登录页最容易把标签/错误/脚注写成 11–12px 灰字 | 字号地板 14px；错误 15px、引导语 15px、脚注 13px（仅 mono 刻度） |
| N | "仪表盘化"——把站点数字摆成卡片 | 登录页没有任何数字，一条都不摆 |
| P | 借来的 SaaS 登录模板配色（紫渐变、玻璃拟态） | 只复用学迹纸墨令牌，全页一个强调色 |
| B | 用渐变/大字块/圆角面板造"品牌感" | 面板只有 1px 发丝线 + 纸底，无渐变无投影 |
| H | 占位文案（"此处应有标语"、"Lorem"） | 全部真实文案，无占位 |
| T | 胶囊堆 | 全页只有一个胶囊（主题切换），且它是主站已有的身份语法 |
| O | 双语眉题（中文大标题 + 英文小眉题） | 无任何英文装饰文字 |
| W | 模板营销话术（"安全登录您的账户"、"欢迎回来"） | 全部换成产品语言：「家庭私有，只有家里人能进。」 |

## 6. 返工测试结论

- **背景依赖测试**：本页无背景图，纸色是令牌不是图槽；方印是身份资产不是装饰背景。不适用，通过。
- **家族连续性测试**：方印、字标三层结构、宋体排印、纸墨令牌、文字按钮语法全部与主站同源；
  遮住方印也能从排印与令牌认出是学迹。通过。
- **模板距离测试**：若只换文案色相即可还原某个通用登录模板——不成立：方印放大、宋体、
  单一朱红、纸底发丝线面板这四条同时在场时无法还原成模板。通过。
- **正向细节门槛**：中文标点（。，）、全角空格、`font-variant-numeric` 未用（无数字）、
  输入框 16px 防 iOS 放大、`env(safe-area-inset-bottom)`、`:focus-visible` 环、
  `prefers-reduced-motion` 关闭过渡——均已落实并在 `proof/` 可见。
